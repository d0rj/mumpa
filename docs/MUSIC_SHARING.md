# Ссылки на музыку

Доступно с Mumpa 1.3.4 на Windows и Android.

- Трек: меню ⋮ → **Поделиться**.
- Альбом, включая отдельный альбом внутри дискографии: **Поделиться** на странице альбома.
- Вся раздача: **Поделиться** на странице исходной коллекции. В ссылку входят все аудиофайлы раздачи.
- Если в альбоме объединены несколько раздач, сначала выбери нужную раздачу.

В окне доступны копирование ссылки и QR-код. На Android кнопка **Отправить** открывает системное меню обмена.

У получателя должна быть установлена Mumpa 1.3.4 или новее. В Windows установка через `Install Mumpa.cmd` регистрирует протокол `mumpa://` для текущего пользователя. Переносная версия без установки может открыть ссылку через **Добавить музыку**. В Android протокол регистрируется при установке APK.

При нажатии ссылка открывает соответствующий трек, альбом или коллекцию. Отсутствующие файлы автоматически попадают в загрузки. Существующие локальные копии используются без повторного скачивания и запроса метаданных у пиров. Для частично скачанного альбома загружаются только недостающие файлы. Ограничения загрузок по Wi-Fi, питанию и объёму хранилища сохраняются. Музыка не начинает играть автоматически.

Используется собственный протокол `mumpa://share/v1`. Некоторые мессенджеры не делают такие адреса кликабельными: скопируй адрес в **Добавить музыку** или открой QR-код сканером, поддерживающим ссылки приложений. HTTPS-переходника с отдельным сайтом нет.

Ссылки работают для торрент-музыки. Для локального файла без раздачи используй существующую передачу по Wi-Fi. Чтобы получить отсутствующую музыку по ссылке, нужны доступные пиры и метаданные раздачи. Ссылка не является передачей файла с устройства отправителя.

## Формат

Параметры: `hash` — 40 шестнадцатеричных символов BTIH; `kind` — `track`, `album`, `release`; `files` — индексы файлов TorrServer (от 1), перечисленные через запятую или диапазонами; `title` — необязательная подпись. Для `release` выбор файлов отсутствует, для `track` указан ровно один индекс. Для альбома сохраняется точный выбор файлов, включая несколько дисков и пропуски неаудиофайлов.

Ссылка содержит только публичный хеш, выбор файлов и подпись. Локальные пути, URL индексаторов, API-ключи и торрент-passkey в неё не попадают. На другом устройстве раздача разрешается через magnet по хешу. Поэтому приватные раздачи, для которых нужен закрытый трекер, могут быть недоступны получателю.

Обработка Windows: команда протокола передаёт URI отдельным аргументом. Если приложение уже запущено, нативный runner передаёт URI через `WM_COPYDATA`, поднимает окно и завершает вспомогательный процесс. Ссылки, пришедшие во время запуска Dart, сохраняются до готовности обработчика. Android принимает холодный запуск и `onNewIntent`; ранние события также сохраняются. Открытия обрабатываются последовательно.

Проверки: `test/music_sharing_test.dart` покрывает формат, точный выбор, офлайн, частичную загрузку, удалённый кеш, ошибочные ссылки, повторные нажатия, стартовые аргументы, канал и копирование в узком интерфейсе.
