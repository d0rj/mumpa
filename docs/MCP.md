# Управление Mumpa через MCP

В Windows открой **Настройки → Доступ для агентов (MCP)**, включи доступ и нажми **Скопировать ключ MCP**. Эта настройка по умолчанию выключена. Сервер работает внутри запущенной Mumpa, включая режим в трее.

Подключи клиент через **Streamable HTTP** по адресу `http://127.0.0.1:37145/mcp`. Передай ключ в заголовке `Authorization: Bearer <ключ>`. При выключении доступа сервер закрывается. При повторном включении Mumpa выдаёт новый ключ. Сервер принимает подключения на IPv4 loopback с указанным адресом и отклоняет запросы с браузерным заголовком `Origin`.

### Пример для Codex CLI

Выполни команды в PowerShell сразу после копирования ключа.

```powershell
$env:MUMPA_MCP_TOKEN = (Get-Clipboard -Raw).Trim()
codex mcp add mumpa --url http://127.0.0.1:37145/mcp --bearer-token-env-var MUMPA_MCP_TOKEN
codex
```

Запущенный таким способом Codex наследует переменную окружения. Для запуска из другого процесса передай эту же переменную в его окружение. Конфигурация MCP хранит имя переменной.

## Инструменты

| Задача | Вызовы MCP без префикса `mumpa_` |
| --- | --- |
| Узнать, что играет, и управлять плеером | `state`, `play`, `transport`, `player_options`, `audio` |
| Просмотреть, пополнить и переставить очередь | `queue`, `queue_add`, `queue_edit` |
| Найти треки, альбомы и плейлисты | `library`, `collection` |
| Изменить избранное, плейлисты и теги | `favorite`, `playlist_create`, `playlist_edit`, `smart_playlist`, `track_edit` |
| Найти музыку и добавить её | `search_online`, `similar_artists`, `find_versions`, `open_source`, `import_local`, `operation` |
| Управлять загрузками и посмотреть статистику | `downloads`, `download_edit`, `listening` |

Схемы аргументов доступны через `tools/list`. Ответы приходят в `structuredContent` и дублируются текстовым JSON. Для следующей страницы передай `next_offset` как `offset`. Позиция воспроизведения и длительность выражены в миллисекундах.

### Включить музыку из медиатеки

1. Вызови `mumpa_library` с `{"kind":"tracks","query":"название или исполнитель","limit":10}`.
2. Передай найденные ID в `mumpa_play` как `{"track_ids":["..."]}`. Для альбома или плейлиста подойдёт его ID. Команда возвращает подтверждение, а состояние буферизации и итог доступны через `mumpa_state`.
3. Для точечной правки очереди вызови `mumpa_queue` и передай `entry_id` выбранного вхождения и `revision` в `mumpa_queue_edit`. У повторений одного трека разные `entry_id`. При `stale_queue` перечитай очередь.

### Найти музыку онлайн

1. Вызови `mumpa_search_online` с `{"kind":"recordings","query":"исполнитель и трек"}`.
2. Передай `operation_id` в `mumpa_operation`. Пока статус `running`, соблюдай `poll_after_ms`. Для отмены передай `cancel: true`.
3. Передай `recording_id` в `mumpa_find_versions` и дождись результата. Передай выбранный `variant_id` в `mumpa_open_source` с `action: "import"`. В результате будут `track_id` и `playlist_id`, готовые для очереди или загрузки.

Для целых релизов используй `kind: "releases"` и полученный `release_id`. `mumpa_open_source` также принимает BTIH magnet и путь к локальному файлу `.torrent`. Действие `inspect` возвращает список аудиофайлов с индексами, а `import` сохраняет коллекцию. Повторный импорт сохраняет уже сделанные правки плейлиста. Операции и ссылки на результаты поиска живут до 20 минут и хранятся в памяти Mumpa.

Ключ позволяет читать медиатеку и управлять ею, включая изменение и удаление плейлистов и удаление управляемых офлайн-копий. Выдавай его клиентам, которым доверяешь. Переносимый экспорт профиля Mumpa исключает ключ.
