# Похожие исполнители: источники и проверка

Проверено 11 октября 2026 года. Для первого подключения подходит **ListenBrainz Labs**: официальный API возвращает MusicBrainz ID, название и оценку совместного прослушивания без ключа и входа пользователя. История прослушивания, лайки, названия раздач, torrent-хеши и данные Jackett этому API не нужны. [Официальная точка входа](https://labs.api.listenbrainz.org/), [описание и выбор алгоритма](https://labs.api.listenbrainz.org/similar-artists).

## Проверенные публичные запросы

```text
GET https://labs.api.listenbrainz.org/similar-artists/json
  ?artist_mbids=<MusicBrainz artist UUID>
  &algorithm=session_based_days_7500_session_300_contribution_5_threshold_10_limit_100_filter_True_skip_30
```

Ответ — JSON-массив с `artist_mbid`, `name`, `comment`, `type`, `gender`, `score`, `reference_mbid`. Алгоритмы представлены динамическим списком на стороне сервиса; фиксированное название может перестать поддерживаться. При ошибке блок можно скрыть и дать повторить запрос. Оценка `score` не является процентом и не доказывает сходство звучания. [Официальный код схемы](https://github.com/metabrainz/listenbrainz-server/blob/master/listenbrainz/labs_api/labs/api/similar_artists.py).

Реальная проверка без Authorization/API key, с User-Agent Mumpa:

| Исполнитель | Результат |
| --- | --- |
| Ежемесячные, `f646239d-504c-479d-a047-8ab4ee22c9f3` | HTTP 200, 7 записей: Слава КПСС (17), СД (15), ИNkkи (15), Да Ст (14), BOOKER (13), MF Док (13), Замай (11). |
| Radiohead, `a74b1b7f-71a5-4011-9441-d0b5e4122711` | HTTP 200, 100 записей; среди первых Nirvana, Red Hot Chili Peppers, Muse и Coldplay. |

Это проверка доступности API и структуры ответа, а не оценка качества всех рекомендаций. Раздача или локальный аудиофайл для рекомендуемого исполнителя могут отсутствовать.

## Ограничения и кеш

Основной ListenBrainz API требует HTTPS, содержательный User-Agent с контактной ссылкой и не более одного запроса в секунду; ответ может содержать заголовки лимита и HTTP 429. Labs в проверенных ответах не прислал заголовки лимита, поэтому клиент использует консервативный интервал **1,1 секунды**. [Правила API](https://listenbrainz.readthedocs.io/en/latest/users/api/index.html#rate-limiting).

`SimilarArtistsRepository` ограничивает ответ 256 КиБ, показывает не более 12 проверенных уникальных исполнителей и исключает исходного исполнителя. Сопоставление выполняется по MBID и `reference_mbid`, без догадок по похожему имени. Запросы одного исполнителя объединяются; отмена одного подписчика не прерывает другого. Таймаут — 10 секунд; очистка общего кеша не допускает позднюю запись из старого запроса. Предоставленный HTTP-клиент остаётся собственностью приложения.

Результаты входят в существующий дисковый FIFO-кеш с его лимитом и очисткой: успешный список хранится 7 суток, пустой — 1 сутки. При повторном открытии и работе без сети используется ещё действительная запись. Ошибки сети и формата не сохраняются как пустые рекомендации. Запрос начинается только после получения идентификатора открытого исполнителя; ввод поискового текста его не запускает.

MetaBrainz указывает, что личное использование его наборов данных бесплатно. Проект ListenBrainz публикует открытые данные и допускает коммерческое использование данных, с отдельными условиями поддержки сервиса. README отдельно указывает GPL для серверного кода. [MetaBrainz datasets](https://metabrainz.org/datasets), [ListenBrainz README](https://github.com/metabrainz/listenbrainz-server#commercial-use).

## Другие варианты

- **ListenBrainz Core:** документированный `GET /1/lb-radio/artist/{MBID}` также работает без токена. В проверке «Ежемесячных» вернул исходного исполнителя и Замая, СД, Да Ст. Он возвращает записи для радио, не оценки сходства, и пропускает исполнителей без подходящих записей. В этом изменении запасной источник не подключён. [Документация](https://listenbrainz.readthedocs.io/en/latest/users/api/core.html#get--1-lb-radio-artist-(seed_artist_mbid)).
- **Last.fm:** `artist.getSimilar` принимает имя/MBID и отдаёт похожих исполнителей; нужна регистрация приложения и API key, хотя вход самого слушателя не требуется. Условия требуют атрибуцию, ссылки и соответствующий кеш; коммерческое применение согласовывается отдельно. Пока добавление ключа не оправдано. [Метод](https://www.last.fm/api/show/artist.getSimilar), [условия](https://www.last.fm/api/tos).
- **Deezer:** публичные `search/artist` и `artist/{id}/related` ответили без токена. Для «Ежемесячных» найден ID `12411710`, список related содержал 20 исполнителей; для Daft Punk ID `27` среди похожих были Justice, Cassius, The Chemical Brothers. Однако официальный портал документации перенаправляет на вход, а MBID отсутствует в ответе. Для текущей задачи ListenBrainz требует меньше неоднозначного сопоставления. [Портал](https://developers.deezer.com/api), [проверенный endpoint](https://api.deezer.com/artist/12411710/related?limit=8).
- **MusicBrainz:** уже подходит для идентификации, псевдонимов и дискографии. Жанры — пользовательские теги; совпадение жанра само по себе не готовый ранжированный список похожих исполнителей. В этом изменении жанровая эвристика не вводится. [API](https://musicbrainz.org/doc/MusicBrainz_API), [жанры](https://musicbrainz.org/doc/Genre).
